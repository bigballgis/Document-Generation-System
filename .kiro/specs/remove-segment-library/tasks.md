# Implementation Plan: Remove Segment Library

## Overview

从文档生成系统中移除段落库（Segment Library）独立共享模块，将组合模板的段落编排从"引用模式"重构为"内联模式"。执行顺序：先重构 DTO 和核心服务 → 数据迁移 → 删除段落库代码 → 前端重构 → 测试更新 → 最终验证。
